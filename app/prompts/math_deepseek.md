## 教学页面实现示范（迁移结构，不照搬题目）

请在内部完成本题解答后，把它设计成一个有 4–6 个学习状态的实验台。主图占主要区域，旁边是当前步骤的一张短解释卡，控件紧贴主图。每个状态包含“现在观察什么、做什么操作、哪一个关系因此清楚了”；下一步改变主图的辅助线、标记或局部示意，而不是仅改标题。最后再显示完整结论与取等/边界解释。按本题所需调整状态数量，不要为凑步骤拆开简单算术。

以下是与本题无关的小示例，只迁移教学组织方式：
题目“半径 R 的圆上点 T 运动，理解横坐标变化”。
状态一：画圆心 O、圆、半径 OT，先认识对象；状态二：从 T 向横轴作垂线，着色直角三角形，引入角 θ；状态三：把邻边 x 与斜边 R 用同色连到 cosθ=x/R，得到 x=Rcosθ，随后开放 θ 滑块；状态四：滑块同时驱动圆上的点、水平投影及旁边 x(θ) 小图，说明最大值的取得条件。即使最后公式可以直接写出，也要让学生看到这个公式从哪两条线段产生。不要把本示例的圆、θ 或公式搬进不相关题目。

可复用的实现方式：
1. 原生 SVG＋普通 JavaScript 即可完成此类几何教学。一个 state 保存当前步骤和真正独立的参数；derive(state) 只算数学坐标与量；render(state) 更新主图、局部图、简短公式和数值。滑块、拖拽、复位、播放、跳到取等位置都调用同一个 setState，避免分叉计算。
2. 数学坐标统一按 X(x)=cx+s*x、Y(y)=cy-s*y 映射；椭圆可用 SVG ellipse，抛物线/函数用足够密的 path。主图等比例。标签用独立偏移量与轻微白色描边，重要对象分层显示。极端位置可等比例调整视口或加局部图，不拉伸坐标伪造关系。
3. 将稳定的 DOM、SVG 层和事件处理器先创建，再更新属性。不要每次拖动都销毁焦点中的控件；指针坐标用 getScreenCTM().inverse() 换算到 SVG，拖拽结束正确释放状态。
4. 参数的命名、来源、可行域和默认值都由原题推导。使用有限滑块展示无界区间时，注明演示范围，并另外说明完整值域与极限；界面默认显示一个有效内部点。
5. 最值/范围步骤不要只放一个最终数字：就近画目标量的函数图、数轴或可比较的几何量，突出当前状态与临界状态，并配必要的推导式。区分示例、观察、证明；等式变形中最重要的一步必须写出来并有相应图形对象。
6. 输出前在内部核查默认状态、一个普通状态、近边界状态及取等状态；每个按钮触发的函数、DOM id 和派生量都要存在。用已有规则渲染公式，确保脱离网络也清晰。

这些要求不需要新增模型调用、外部工具或工作区访问。直接根据本次附带的原题图片完成整个 HTML。
