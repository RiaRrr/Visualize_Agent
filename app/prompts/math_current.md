# 数学学科经验

先逐字核对题图里的符号、坐标、点名、括号、绝对值、等号与严格不等号，在内部独立求解并检查定义域、端点和退化状态。题设命名的点不可擅自当成原点；图中每个点、曲线分支和交互状态都必须满足原始条件。图形、标注、公式和结果须由同一组合法参数计算。

教学图先呈现题设给出的对象与约束，再通过辅助线、角度、长度、面积、轨迹或坐标展示必要的条件转化。若引入斜率、参数或控制量，先在图上说明它与题设条件的关系、为什么可这样表示以及合法范围，再让学生操作；示例值不得冒充唯一解。对重要转折，可用局部图或主图的分步高亮与状态变化；图上的量应直接对应公式。

解析曲线应按函数准确绘制，在实际显示尺寸下不能有可见折角；顶点、交点和拖拽点要从同一数学表达式求出。滑块和拖拽只开放合法状态，图形、填色、标注、公式数值与结论同步变化。不可取的边界可演示逼近，不画成已经取得。

数学符号应在离线浏览器中稳定显示。不要依赖 `₁⃗`、`x⃗` 这类下标与组合箭头叠加的 Unicode 字符，或少见字体字形来表示向量；优先用 SVG 画箭头，用 HTML `<sub>` 排下标，或用简单 CSS 将箭头与变量排版。图中标签也须采用可读的表达，避免缺字方框、重叠与过密标注；检查初始画面和交互后的状态。

可借鉴 interactive-whiteboard、math-teacher、math-skills 的教学思路，以及本地 interactive-math-html、math-visualization-workflow 两套 skill 的坐标映射、统一状态、可操作图和边界检查方法。把这些方法写进最终单文件页面，不要求运行 skill 脚本或调用额外工具。

## 数学与交互的一致性检查

- 求斜率时明确使用哪两个点，先写坐标差再化简；求距离、面积、数量积时也要让式子里的对象与图中命名一一对应。不得让正文采用一个公式、脚本采用另一个公式。输出前以一个合法普通值和一个临界附近值交叉核对公式、几何与显示结果。
- 先由全部题设确定可行域，再设置控件的 min/max/default。默认值、复位值、播放路径与“最优位置”按钮都必须合法；不能把大部分滑块范围设在无解区，再靠隐藏点线掩盖。若为观察不可取边界而截取有限演示区间，要明确它只是显示范围，不是完整数学定义域。
- 取值范围不仅检查上下界，还检查退化构型、点重合、分母为零和区间内部被排除的参数。区分“当前值”“估计范围”“完整值域”“下确界”和“可达到的最小值”，明确开闭端点与取等条件。定点或最值可以在推导后写成常量，但不能以未经推导的常量反过来构造图形并宣称得到验证。
- 几何主图使用等比例坐标；长度、角度、面积与曲线上的点从数学坐标映射得到。示意压缩或函数图的非等比坐标要明确标注，不能用于证明几何角度或长度比例。控制辅助线与标签的显示时机，避免全程叠加所有对象。
- 优先使用原生 SVG 的 ellipse/path/line/text 和普通 JavaScript；少量可标注几何对象不需要额外绘图库。用 HTML sub/sup、分数 CSS 或 SVG 排版公式；仅写出 LaTeX 的反斜杠与分隔符不会自动渲染，不得把未渲染源码直接展示给学生。
