# 数学学科经验

先逐字核对题图里的符号、坐标、点名、括号、绝对值、等号与严格不等号，在内部独立求解并检查定义域、端点和退化状态。题设命名的点不可擅自当成原点；图中每个点、曲线分支和交互状态都必须满足原始条件。图形、标注、公式和结果须由同一组合法参数计算。

教学图先呈现题设给出的对象与约束，再通过辅助线、角度、长度、面积、轨迹或坐标展示必要的条件转化。若引入斜率、参数或控制量，先在图上说明它与题设条件的关系、为什么可这样表示以及合法范围，再让学生操作；示例值不得冒充唯一解。对重要转折，可用局部图或主图的分步高亮与状态变化；图上的量应直接对应公式。

解析曲线应按函数准确绘制，在实际显示尺寸下不能有可见折角；顶点、交点和拖拽点要从同一数学表达式求出。滑块和拖拽只开放合法状态，图形、填色、标注、公式数值与结论同步变化。不可取的边界可演示逼近，不画成已经取得。

数学符号应在离线浏览器中稳定显示。不要依赖 `₁⃗`、`x⃗` 这类下标与组合箭头叠加的 Unicode 字符，或少见字体字形来表示向量；优先用 SVG 画箭头，用 HTML `<sub>` 排下标，或用简单 CSS 将箭头与变量排版。图中标签也须采用可读的表达，避免缺字方框、重叠与过密标注；检查初始画面和交互后的状态。
