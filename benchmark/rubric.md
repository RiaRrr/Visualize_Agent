# 人工与独立模型评价标准 v2

面向刚读题、尚不知道解法的学生。先核对原题，再操作 HTML；不知道或未检查的项目留空，不用 0 代替。
参考答案来自题库，尚未逐题独立审定。发现疑问请选择“参考答案疑问”，在备注说明；该样本不进入 judge 排名，直至核查。

## 五维评分（1–5）
- 一致性：是否保留原题对象、条件、各小问和允许范围。
- 正确性：推导、计算、符号、边界、结论和图中数值是否正确。
- 页面效果：桌面显示是否清楚，图形、文字与公式有无重叠、裁切。此次不评分手机适配。
- 交互效果：控制量来历和范围是否合理，图形、公式、数值是否同步，反馈是否靠近操作。无需交互的题可凭恰当静态表达得高分。
- 教学效果：代入具备相应高中基础、刚读完题但不会做本题的学生，检查能否通过可视化循序渐进地理解条件转化、每步依据和答案由来。不能用评审者已知的解法、源码或参考解析补齐页面缺失的解释。关注学生哪里会卡住、信息量和理解难度是否合理，以及学完能否说明为什么这样解。

教学效果专项锚点：1=基本学不到解法或受到核心误导；2=关键步骤需要预先会做题或外部讲解；3=主线可跟随，但存在重要解释不足或明显理解负担；4=关键转化与图形对应清楚，仅有局部障碍；5=从题设到答案循序渐进，关键关系都有可见依据，无需预先会做本题即可理解并复述。关键步骤必须靠评审者补全时最高2分。此评分是基于页面证据的判断，不代表已经验证真实学生的学习效果。
核对各图坐标轴及量的含义，简化模型与原题真实关系不能混同。例如粒子计数折线不能冒充电导曲线；一行“示意/近似”说明不能抵消关键关系未教清楚的问题。没有原始实验数据时，不要求伪造精确拟合。

统一锚点：1=严重缺陷，基本不达标；2=有明显问题，需要较大修改；3=基本可用，仍有明显不足；4=良好，仅少量局部问题；5=完整清晰，该维度未发现实质问题。
## 综合评分（0–5，独立填写，不自动平均）
0=无法作为该题教学材料使用（如核心结论错误、主要内容缺失、关键功能彻底失效）；1=问题很多；2=部分可用，须明显修正；3=基本可用；4=教学效果良好；5=优秀且没有发现实质缺陷。
不要因颜色漂亮抵消数学错误；也不要仅因存在少量改进建议就自动判 0 分。
## 建议检查顺序
1. 对照题图与答案，核对是否遗漏小问、误读图形和边界。
2. 从第一步读起，尝试下一步、回退、重置；观察思路是否连贯。
3. 将关键滑块移到中间与边界，尝试可见按钮；核对图文联动和约束。
4. 填写五维与综合评分；关键错误写具体位置、触发操作和实际现象。

评分时隐藏生成模型、workflow、轮次及模型分数。由用户本人给出的评分才标为 human；模型/脚本不得代填。
